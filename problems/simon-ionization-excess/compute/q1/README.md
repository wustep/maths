# q1 — Simon ionization excess

Replay of the published non-asymptotic bounds on $N_c(Z)$, plus
attempts to tighten the Hundertmark–Pattakos–Schulz remainder and to
certify small-$Z$ objects.

## Record this folder compares to

- Lieb (1984): $N_c<2Z+1$.
- Nam, arXiv:1009.2367v3: $N_c<1.22Z+3Z^{1/3}$.
- Hundertmark–Pattakos–Schulz, arXiv:2504.18487v1:
  $N_c<1.1185Z+4Z^{1/3}$ for $Z\ge4$, and Prop. 2.5 with remainder $3.90$.

A floating DFT energy is not a bound. An incomplete search is not a
lower bound.
