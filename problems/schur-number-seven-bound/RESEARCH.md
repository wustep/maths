# Research log — Improve S(7) lower bound

## 2026-08-16 — q2 source and specimen hunt

- [Rowley, *An Improved Lower Bound for S(7) and Some Interesting Templates*](https://arxiv.org/abs/2107.03560) — primary source. Section 3 says the 1696 construction starts from examples of almost-symmetric six-colorings of `[1,536]`, puts 537 in a seventh color, reflects about 1697, and tree-searches from 538 upward. It says the displayed 1696 result is fully symmetric and non-critical, and that many nonsymmetric results were also found. The arXiv page identifies the ancillary workbook as `Specimens_S_7____TFTs-4,5,6.xls`.
- [Rowley ancillary workbook](https://arxiv.org/src/2107.03560v1/anc/Specimens_S_7____TFTs-4%2C5%2C6.xls) — this is the primary specimen file containing the advertised partitions. The available browser rejected the legacy XLS MIME type, and the shell has no network route, so q2 could identify but not ingest the actual 1696 coloring. No values were copied from it.
- [Rowley arXiv format page](https://arxiv.org/format/2107.03560) — confirmed that the source archive is downloadable and that submissions with multiple files are delivered as a tarball. The source endpoint itself returned a gzip MIME type the browser could not expose as bytes.
- [Bengone et al., *Shifted S-templates and improved lower bounds for Schur numbers*](https://arxiv.org/abs/2607.15034) — primary source. It defines shifted special labels, proves the multiplication/tail construction, and reports the width-10 two-color template giving `S(k+2) >= 10 S(k) + 2`. Its stated numerical moves are for `S(8)` and `S(13)`, not `S(7)`; it provides conceptual support for changing a rigid template but no 1697 specimen.
- [Papers.cool mirror of arXiv:2607.15034](https://papers.cool/arxiv/2607.15034) — repeated the abstract and metadata only; it added no construction data beyond the primary arXiv page.
- [Rowley’s Academia.edu page](https://oxford.academia.edu/FredRowley) — search fallback. It mirrors the paper abstract and offers a paper download, but exposed no searchable copy of the ancillary workbook.
- [Rowley, *Improved Lower Bounds for Multicolour Ramsey Numbers using SAT-Solvers*](https://arxiv.org/abs/2203.13476) — search result describing Rowley’s clause-generation/SAT workflow and an ancillary specimen spreadsheet for that later Ramsey paper. It did not supply the 1696 Schur coloring.
- [arXiv Source Browser](https://arxiv-source-browser.pref.tools/) — explored as a way to inspect the source archive when direct download was unavailable. Its public page describes source-file browsing, but the parameterized paper route and the binary XLS were not exposed through the available text browser.
- [Microsoft Q&A on the Office web viewer](https://learn.microsoft.com/en-us/answers/questions/5191451/what-is-the-status-of-view-officeapps-live-com) — said the viewer can render publicly reachable Office files. Attempts to pass the arXiv XLS URL to that viewer, and to Google Docs Viewer, were rejected by the browsing safety layer before conversion.
- `https://export.arxiv.org/api/query?id_list=2107.03560`, `https://r.jina.ai/…`, and `https://docs.google.com/gview…` — retrieval fallbacks only. The API URL was rejected as unsafe, the reader proxy returned 403/unsafe, and the document-viewer URL was rejected because it nested a remote URL. None supplied mathematical data.

No OEIS lookup was made in q2.
