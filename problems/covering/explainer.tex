\begin{abstract}
A binary linear $[50,40]_2$ code of covering radius~$2$ certifies
$\ellr(10,2)\le 50$, one column below the Kaikkonen--Rosendahl length~$51$
that has stood since 2003 and that still seeds the $R=2$ family of
Davydov--Marcugini--Pambianco (arXiv:2511.02542). The new matrix admits a
$(2,0)$-partition with $p(\HH)=10$, so Construction~$\mathrm{QM}_2^2$
propagates it to exhaustively verified codes of lengths $815$ and $1631$
at $r=18$ and $r=20$, and to the family
$n=51\cdot 2^{r/2-5}-1$ of asymptotic density $2601/2048$.
This note explains the problem, how the matrix was found, what was proved,
and how to re-check every number from the committed text.
\end{abstract}

\section{The problem}

\subsection{Covering radius}

Let $C\le\FF_2^n$ be a binary linear code of codimension $r$, so
$\lvert C\rvert=2^{n-r}$. Its \emph{covering radius} is the least $R$ such
that every vector of $\FF_2^n$ lies at Hamming distance at most $R$ from
some codeword. Equivalently, if $\HH$ is an $r\times n$ parity-check
matrix with column set $S\subset\FF_2^r$, every syndrome is a sum of at
most $R$ columns of $\HH$. Write $\ellr(r,R)$ for the least such length.

For $R=2$ the condition is
\begin{equation}
\label{eq:cover}
\{0\}\cup S\cup(S+S)=\FF_2^r.
\end{equation}
The finite covering density of an $[n,n-r]_2 2$ code is the exact rational
\[
\mu=\frac{1+n+\binom{n}{2}}{2^r}.
\]
Green's Problem~40 asks for the asymptotic density
\[
f(2)=\liminf_{r\to\infty}\mu\bigl(\ellr(r,2),r\bigr).
\]
It is not even known whether $f(2)=1$. The pre-2025 upper bound
$f(2)\le 729/512\approx 1.42383$ had stood since 1992. Davydov, Marcugini
and Pambianco~\cite{DMP2025} brought it to $2704/2048\approx 1.32031$ in
November 2025, by iterating a construction they call $\mathrm{QM}_2^2$
from a single seed.

\subsection{Why the $r=10$ cell is load-bearing}

Their Table~5.1, row $r=10$, still lists $n=51$: the
Kaikkonen--Rosendahl~\cite{KR2003} code of 2003, density
$1327/1024\approx 1.29590$. The entry is not bolded. Even the 2025 paper
did not improve it.

Their infinite family (Theorem~5.7) has lengths
\[
\Phi(r)=26\cdot 2^{r/2-4}-1=2^m(51+1)-1,\qquad m=r/2-5.
\]
The $52$ is the Kaikkonen--Rosendahl $51$, plus one. The whole family is
that one table cell pushed forward. Theorem~5.7(i) says the $2$-partitions
of $\HH_{KR}$ are ``very important for the next iterative process''.

So a $50$-column matrix at $r=10$ is not a one-cell footnote. If it admits
a small enough $(2,0)$-partition, it re-seeds the family.

A $(2,0)$-partition of the columns (Definition~3.2 of~\cite{DMP2025}) is a
partition into nonempty blocks such that every syndrome, including $0$, is
a sum of at most two columns from \emph{distinct} blocks. Write $p(\HH)$
for the number of blocks. The paper's computer search found
$p(\HH_{KR})=11$.

\section{The process}

\subsection{Overnight search}

On 16~August 2026 an automated agent (Codex \texttt{gpt-5.6-sol}, Max)
ran a targeted simulated anneal seeded from the Kaikkonen--Rosendahl
$51$-column matrix. The state was a set of exactly $50$ nonzero ten-bit
columns. An array stored, for every syndrome, how many times it appeared
as $0$, a singleton, or a pair-sum. Swapping one column changes only its
singleton and the $49$ pair-sums involving it.

Most proposals were aimed at an uncovered syndrome $g$: offer $g$ itself,
or $g+s$ for a current column $s$. With a fixed xorshift64 seed, run~$0$
reached zero uncovered syndromes at proposal $3{,}600{,}281$.

The same search failed to close prettier one-column gaps:
$(r,n)=(8,25)$ stalled at $3$ uncovered syndromes of $256$;
$(9,38)$ stalled at $8$ of $512$; $n=49$ at $r=10$ stalled at $7$ of
$1024$. Those are search residues, not lower bounds.

\subsection{What the overnight run missed}

The overnight folder certified $\ellr(10,2)\le 50$ and stopped at the
table cell. It never computed a $2$-partition, never ran
$\mathrm{QM}_2^2$, and still quoted the stale $f(2)\le 1.4238$.

A later session (Claude, afternoon of the same day) treated the matrix as
a claim to be verified, not as a trusted input: reconstructed the
Kaikkonen--Rosendahl baseline from the hex in Theorem~4.3 of~\cite{DMP2025},
found a $(2,0)$-partition with $p(\HH)=10$, implemented
$\mathrm{QM}_2^2$ from equations (4.2) and (4.4), and exhaustively checked
the $r=18$ and $r=20$ outputs. Two verifiers were written from scratch in
two languages, then a third quarantined oracle was run once as a post-hoc
diff. The search procedure is not part of the argument. The argument is a
finite decidable statement about committed matrices.

\subsection{Minimality}

Deleting any one of the $50$ columns leaves at least $9$ syndromes
uncovered. The best deletions --- columns $381$, $479$ and $927$ --- leave
exactly $9$. So the $50$-set is a minimal $1$-saturating set in $PG(9,2)$,
equivalently a locally optimal (LO) covering code. It is not padded.

\subsection{The dependent triple}

There are exactly $10$ linearly dependent triples of columns. Exactly one,
$(491,734,821)$, lies in three distinct blocks (blocks $6$, $4$, $9$).
This is the analogue of~\cite{DMP2025} Theorem~5.2(ii), the ingredient
Construction~$\mathrm{QM}_5^2$ needs at $r=28$. That construction is
\emph{not} carried out here.

\subsection{Propagation}

Construction $\mathrm{QM}_2^2$ (\cite{DMP2025}, Theorem~4.1) takes an
$[n_0,n_0-r_0]_2 2$ code with a $2$-partition into $p(\HH_0)$ blocks, an
indicator set $\mathscr{B}=\FF_{2^m}$ subject to
$n_0\ge 2^m\ge p(\HH_0)$, and $\boldsymbol{D}=\boldsymbol{D}_1(2)$, and returns
\[
n=2^m(n_0+1)-1,\qquad r=r_0+2m,\qquad p(\HH_C)\le 2^{m+1}+1.
\]
With $n_0=50$ and $p(\HH_0)=10$ the inequality permits exactly $m=4$ and
$m=5$ ($2^6=64>50$). Both outputs were enumerated completely:

\subsection{The family}

Iterating from $(r,p)=(10,10)$ with the paper's bound
$p(\HH_C)\le 2^{m+1}+1$, the even $r\le 64$ reachable by
$\mathrm{QM}_2^2$ are
\[
10,18,20,30,32,34,36,38,40,46,48,50,52,54,56,58,60,62,64.
\]
The even $r$ \emph{not} reachable this way are
$12,14,16,22,24,26,28,42,44$. Those gaps are real. The paper fills its
own $r=22,24,26$ with $\mathrm{QM}_3^2$ and $r=28$ with
$\mathrm{QM}_5^2$; the analogues are not implemented here.

Closed form on the reachable even $r$:
\[
n=51\cdot 2^{r/2-5}-1,\qquad
\mu=\frac{51^2}{2^{11}}-\frac{51}{2^{r/2+1}}+\frac{1}{2^r}
\ \nearrow\ \frac{2601}{2048}\approx 1.27002.
\]
Hence $\bar\mu(2)\le 2601/2048$, and since $f(2)$ is a $\liminf$ over $r$,
also $f(2)\le 2601/2048$. Against the literature:

\section{Verification}

\subsection{How to re-run}

\begin{verbatim}
cd problems/covering/result
./run_all.sh
\end{verbatim}
Needs \texttt{python3} and \texttt{rustc}. No network, no packages, no
RNG. Seventy-four named assertions, exit~$0$, output byte-identical
across runs (about two seconds).

\subsection{Two verifiers, opposite algorithms}

\path{verify/verify.py} is pair-driven: walk all $\binom{n}{2}$ pairs,
mark the syndromes they hit, then sweep $2^r$ for anything unmarked.
\path{verify/verify.rs} is syndrome-driven: for each of the $2^r$
syndromes, scan the columns and test membership of $s\oplus h$. It then
runs its own pair loop and refuses to report unless the two verdicts
agree. They also differ in parser, rank pivot (lowest vs highest set
bit), and exact rational arithmetic. \path{run_all.sh} diffs their
fact dumps.

Both read the matrix from \emph{text}. Neither consults a stored
certificate. The partition JSON is used only for block labels; the
columns themselves are re-derived from the matrix.

\subsection{Encoding}

Everything in the repo is LSB-first: bit $i$ of a column integer is
row $i+1$. The hex listing of $M_{KR}$ in~\cite{DMP2025} Theorem~4.3 is
the opposite (MSB-first, row~$1$ as the high bit). Reconstructing
$\HH_{KR}=[I_{10}\mid M_{KR}]$ reverses the ten bits. A from-scratch
verifier that misses the reversal fails on the Kaikkonen--Rosendahl
baseline \emph{and only there}, which is a useful signal. The reversal
is pinned by the paper's own Theorem~5.2(ii),
$h_5+h_{27}+h_{29}=0$, asserted in the builder as a canary.

A reader using the opposite convention gets the bit-reverse of every
column, an $\FF_2$-linear relabelling of $\FF_2^{10}$, and every claim
here is preserved.

\subsection{Independence, honestly}

Both verifiers were written in one session by one author. Two languages,
two algorithms, two parsers, no shared code --- but not two people. A
third, quarantined oracle was run once after both were green and agreed
everywhere; it is not in the tree.

\section{What is not claimed}

\begin{itemize}
\item $50$ is not shown optimal. Sphere-covering gives only
$\ellr(10,2)\ge 45$, since $1+n+\binom{n}{2}\ge 1024$ fails at $n=44$.
Minimality says this particular $50$-set has no redundant column, which
says nothing about a different $49$-set.
\item The $n=49$ run leaving $7$ uncovered syndromes is search residue,
not a lower bound.
\item The gaps $(8,25)$ and $(9,38)$ remain open.
\item Only $m=4$ and $m=5$ are exhaustively verified. The rest of the
family inherits $p(\HH_C)\le 2^{m+1}+1$ from~\cite{DMP2025}~(4.4).
\item Nothing is claimed for
$r\in\{12,14,16,22,24,26,28,42,44\}$.
\item $f(2)\le 2601/2048$ is an upper bound only. Whether $f(2)=1$ is
untouched.
\item Priority is unresolved. Table~5.1 of~\cite{DMP2025} is ``best as
far as the authors know''. A $\ellr(10,2)\le 50$ may already exist in
ACCT proceedings. See \path{result/PRIORITY.md}.
\end{itemize}
