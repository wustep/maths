# Writing

README, PROBLEM.md status, explainers, notes, and GitHub PR titles
and bodies. ATTACK.md stays chronological. Walkthroughs stay
`refs/walkthrough-style.md`.

State the claim in one sentence.
Define a symbol the first time it appears.
Cite the record you beat, or say the record stands. Once.
Put the caveat once, in a status line.
A failed search with a verifier is residue.

One idea per sentence. Active voice. Name the actor. Prefer the
verb: verify, not "perform a verification." No em dashes. Period
or comma. Pick one verb for the same act.

## Pull requests

The title is the change.
The body says what changed and how to replay or check.
No "this PR aims to." No chatbot close.
