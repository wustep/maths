# Meta loop

1. One folder per problem. Solver writes PROBLEM / ATTACK / WALKTHROUGH / RESEARCH.
2. Append every reusable lesson to `notes/process/learnings.md` the same day.
3. Watchers read the other solver's ATTACK.md and paste one stealable idea
   into learnings, then the orchestrator relays it.
4. Do not invent a dent. A failed search with a verifier is the product.
5. Style: `refs/walkthrough-style.md`.
